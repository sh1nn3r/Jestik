# Shopify policy text (paste into Settings → Policies)

The Shopify connector lacks the `write_legal_policies` scope, so these must be pasted by hand.
In each policy editor, click the `<>` (show HTML) button, select all, and paste the file contents.

| Shopify policy | File |
|---|---|
| Refund policy | refund.html |
| Privacy policy | privacy.html |
| Shipping policy | shipping.html |
| Contact information | contact.html |

Terms of service: only Section 18 needs fixing. Replace its sentence with:
"These Terms of Service are governed by the laws of the State of California, United States, and any disputes will be handled in the courts of Los Angeles County, California."
