# Theme customizations

Files added to the Chrono Candy Shopify theme.

- `snippets/cc-contact.liquid`: floating "CC" contact button and slide-out panel (text us, book an appointment by email).
- `snippets/custom-code-body.liquid`: renders the contact snippet before `</body>`.

Uploaded to the unpublished theme "Chrono Candy – Bezel + Contact Button" for review. Preview: https://chronocandy.com/?preview_theme_id=150137471018
